# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [0.1.11] - 2026-11-04

### Added
- Added `opfs.observe(pathOrHandle, callback, options)`
- Added `opfs.supported()`
- Added types `OpfsSupported`, `OpfsObserverCallback`, `OpfsObserverOptions`, `OpfsCreateWritableOptions`
- Change all paths to start with `/`

## [0.1.10] - 2026-11-03

### Added
